## 4. Allowed Changes

- **P0 — Critical**（允许直接修复）：
  Secret 泄漏 / 数据损坏 / State 丢失 / Production 无法运行 / GitHub Actions 完全失败 / Lark 完全无法发送 / OpenAI 完全无法调用 / 严重错误报告 / 安全问题
- **P1 — Blocking Bug**（允许修复）：
  Industry / Competitor E2E 无法完成 / State 无法跨 Run 恢复 / GitHub Secret 无法同步 / Bootstrap 无法完成配置 / 核心 Collector 大面积失效 / 关键报告数据错误
- 上述修复所需的必要测试与最小文档修正

## 5. Disallowed Changes

- 新功能 / 投机性重构 / 架构扩展 / 新基础设施
- 无生产证据的新 Source / 新 Wallet
- 无关清理（"顺手优化"）
- 修改 Prompt / Scoring / 模型路由（除非 P0/P1 证明必要）

**Smallest Safe Fix 规则**：修 Bug 时只修 ROOT CAUSE + 必要测试 + 必要文档。禁止顺便重构、顺便加 Source、顺便改 Prompt、顺便引入新框架。

**Agent 自主扩规禁止**：Agent 发现"可以更好"但不属于当前真实 Blocker 时，必须记录到 `docs/V0.2_BACKLOG.md` 后继续当前任务，不得自动实现。
